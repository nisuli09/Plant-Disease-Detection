# 🌿 Plant Disease Detection System

A simple end-to-end computer vision project that uses a Convolutional Neural Network (CNN) to classify plant leaf images as **healthy** or **diseased**.

## Project Overview



```text
Leaf Image
    ↓
Image Preprocessing
    ↓
CNN Model
    ↓
Healthy / Diseased
    ↓
Confidence Score
```

## Technologies

- Python
- TensorFlow / Keras
- OpenCV/Pillow
- FastAPI
- HTML, CSS and JavaScript
- Jupyter Notebook
